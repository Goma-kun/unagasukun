# うながすくん

時間が来たら「いまは○○の時間です」と教えてくれる、誘導型の習慣化支援 Chrome 拡張機能です。
サイトをブロックしたり記録を強要したりせず、決めた時間に決めたことを思い出させることに徹します。

## 機能（v0.2.0）

- **予定の登録**：時刻＋やること＋曜日（未選択なら毎日）をサイドパネルから登録
- **時間通知**：設定時刻に通知を表示。「できた」「今日はスキップ」ボタンでその場で記録
- **時間帯ブロック**：終了時刻（任意）を入れると、進行中はツールバーアイコンに残り分数を表示し、
  終わりに「できましたか？」と聞いて記録まで閉じる
- **「実際は」記録**：スキップした予定・時間が過ぎた予定に、実際にやっていたことを
  ワンタップのチップ（別の作業/休憩/ブラウジング/気分が乗らず/その他）で残せる。
  自動追跡はしない（自己申告のみ）
- **連続記録**:「🔥n日」を今日の予定に表示。スキップでは連続は切れない
- **今日の予定**：サイドパネルに今日の予定を時刻順に表示。済んだものには ✓ が付く
- **すぐ変えられる**：予定の編集・一時停止（休む/再開）・削除がワンクリック
- **切り離し表示**：⧉ でサイドパネルから独立した小窓に切り離し、⇥ でサイドパネルに戻せる（二重表示はしない）

## 設計方針

- 権限は `storage` / `alarms` / `notifications` / `sidePanel` のみ
- host_permissions・content script・外部通信なし
- データはすべて `chrome.storage.local` に保存（外部に送信しない）

## 開発

- 読み込み: `chrome://extensions` → デベロッパーモード → 「パッケージ化されていない拡張機能を読み込む」→ `extension/` を選択
- テスト: `node test/logic_test.mjs`（スケジュール計算ロジックの単体テスト）
- プレビュー: `sidepanel.js` は chrome.storage が無い環境では localStorage にフォールバックするため、`extension/` を静的サーバーで開けば UI を確認できる（通知とアラームは実 Chrome でのみ動作）
